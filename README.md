# PopX — Account Flow UI (React)

A pixel-accurate React implementation of the **PopX account flow**, built from an **Adobe XD design
specification** as a front-end assignment.

**[Live demo →](https://pop-x-account-ui.vercel.app/)**

## What this is

Three screens of a signup and login flow, implemented to match the supplied design: layout, spacing,
type scale, input states and screen transitions.

The point of the exercise was fidelity, not features — reproducing a design accurately is a different
skill from inventing one, and it's the part most portfolio projects skip.

## Screens

- Landing screen with primary and secondary calls to action
- Create account form with field-level validation
- Login screen
- Profile screen after signup

## Stack

- React
- React Router
- Tailwind CSS
- Vite

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build
npm run preview  # preview the production build
```
